# GB Studio collection: hosted ROMs

Cartouche lists about a hundred games made with [GB Studio](https://www.gbstudio.dev/). It hosts only the
ones whose authors' licenses allow redistribution of the whole ROM (code and assets), each exactly as its
author released it. Every other game in the collection links to its author's own page.

Each file is a separate program that Cartouche loads as data, like a file the player adds. The app downloads
one only when the player asks (it is not part of the offline app shell), checks its SHA-1, and stores it in the
player's browser. Like every Game Boy ROM, each header contains the logo bitmap the original hardware checks at
power-on; it is part of the authors' releases.

## Dawn Will Come

- Authors: art, writing and design by H0lyhandgrenade; programming and art by eishiya; music by Kezia Salmon
  (Les Beaux Plastiques). A GB Compo 2021 entry.
- Official page: https://eishiya.itch.io/dawn-will-come
- Source: https://github.com/eishiya/DawnWillCome
- Licenses, as stated in the source repository README ("Licenses") and on the official page:
  - Artwork and music: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Artwork © H0lyhandgrenade
    and eishiya, music © Kezia Salmon.
  - All of the code, including the scripts built in the GB Studio editor: MIT License. "Original GBS engine code
    © 2020 Chris Maltby, Dawn Will Come-specific code © 2021 eishiya" (MIT text below).
- File: `DawnWillCome.gb` from its Homebrew Hub entry
  (https://github.com/gbdev/database/tree/master/entries/dawn-will-come), byte for byte identical to the ROM the
  authors serve in their own itch.io build. Changes: none (renamed to `dawn-will-come.gb`).
